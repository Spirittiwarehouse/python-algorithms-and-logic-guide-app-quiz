## 📖 The Problem With Traditional Learning

Let's be honest. Most algorithm courses are boring. You watch a 40-minute video of someone drawing trees on a whiteboard, you nod along, and then you try to solve a problem and realize you have no idea what you are doing. 

**Python Algorithms And Logic Guide App Quiz** was built to fix this broken learning model. It is a hands-on, interactive quiz application that forces you to actively engage with the material. Instead of passively reading, you are constantly tested, challenged, and given instant feedback.

This repository is a complete, open-source learning platform. It contains a curated library of over 500 algorithm and logic problems, ranging from beginner-friendly array manipulations to advanced dynamic programming challenges. Every question includes a detailed explanation, visual diagrams, and a reference solution written in clean, Pythonic code.

Whether you are a student preparing for your first internship, a bootcamp graduate preparing for technical interviews, or a professional brushing up on computer science fundamentals, this app adapts to your pace and keeps you motivated.

## 🧠 Under The Hood: The Sandboxed Execution Engine

Running user-submitted code on a server is a massive security risk. A malicious user could write a script to delete files, mine cryptocurrency, or launch a DDoS attack. 

To solve this, every submission is executed inside an isolated **Docker container** with strict resource limits. The container has no network access, no access to the host file system, and is limited to 128MB of RAM and a 2-second CPU time limit. The code is injected, executed, and the output is captured. If the code exceeds the time limit or uses too much memory, it is killed and flagged as a timeout.

This ensures a safe, fair, and reliable testing environment for every user, while giving you the realistic experience of solving problems under pressure.
